# RTX 3070 小模型推理 TTFT 实测报告

测量日期：2026-10-13（上海时间）。已完成 **46 个正式配置 × 48 条有效样本 = 2208 条正式测量**；另有 40 条预试验及 776 条预热，总计 **3024 次请求**。失败 0，实际缓存复用 token 最大值 0。所有正式配置均覆盖 48 个不同且配对的样本 ID。见 [验收记录](../results/validation.json)。

正式配置中的观察最低均值为 **smol500-q8，24.22 ms**。累计阶梯独立重测的起点为 26.82 ms，终点为 1301.54 ms，整体约 48.5 倍。除累计叠加的大模型、竞争和高并发末端两档外，其他正式配置的均值均低于 600 ms。置信区间重叠时，均值排序不是确定的性能排名。

## 计时和控制

TTFT 为本机 HTTP 请求发出前，到首个非空生成文本 SSE delta 的单调时钟耗时。响应头、角色事件、空事件和心跳不计为首 token。逐字节读取 SSE，避免默认缓冲延迟。首个可见文本可能晚于内部首个生成 token，此处不是纯 GPU 内核时间。

计时包含本机传输、服务端视觉处理、prefill、调度、排队和首文本输出；排除权重加载、预热、客户端数据准备及视频解码/采帧。每档两块各 24 条，配置顺序每块重新随机化，每块每档另做 8 条预热。预试验、预热、正式输入 ID 分离；温度 0、固定种子、32 token 输出预算、禁用前缀复用。所有请求均保留。

服务器 prompt_ms 与客户端 TTFT 分别保留；差值含排队、调度、预处理和传输，**不是单独测得的排队时间**。并发条件均值的 CI 按完整波次重采样；高并发波次数少，CI 是探索性估计。

硬件为 RTX 3070 8 GB、i5-13600K、约 32 GiB 内存，Windows 11，llama.cpp b11577 / CUDA 12.4。显卡原有功率上限 **154 W**，驱动默认值为 220 W，实验未改功率或频率。遥测最高采样显存约 **2542 MiB**，不保证捕获瞬时峰值。日志确认全部语言模型层及视觉编码器使用 CUDA；多个用户共享一份模型。

## 累计阶梯

这是独立测量，按计划只改变下一项配置。系列切换含 tokenizer 等固有模型差异；精度单列一步，避免与模型规模同时改变。

| 配置 | 实际输入 token 均值 | TTFT 均值 ms | 95% CI ms | 中位数 ms | p95 ms | 有效/尝试 |
|---|---:|---:|---:|---:|---:|---:|
| 0：SmolVLM2-500M Q8，短文本，单用户 | 94.19 | 26.82 | 24.46–29.11 | 27.11 | 40.21 | 48/48 |
| 1：仅切换为 LFM2-350M Q8 | 93.27 | 29.49 | 26.46–32.34 | 34.29 | 41.59 | 48/48 |
| 2：仅切换为 Q4_K_M | 93.27 | 27.38 | 24.82–30.07 | 27.40 | 40.61 | 48/48 |
| 3：上下文预算 64 → 512 | 540.21 | 42.59 | 40.05–45.08 | 43.84 | 55.03 | 48/48 |
| 4：上下文预算 512 → 2048 | 2072.12 | 87.57 | 85.03–90.23 | 87.42 | 99.74 | 48/48 |
| 5：仅切换为 LFM2-1.2B Q4 | 2072.12 | 167.82 | 165.37–170.26 | 171.99 | 176.13 | 48/48 |

![累计阶梯](../results/figures/staircase.png)

保留的回落：step-1-model-lfm350-q8 → step-2-precision-q4，均值变化 **-2.11 ms**，配对 95% CI [-6.08, 1.89] ms。


整体上升，但**每一阶并非严格单调**；精度切换的小幅回落及不确定性完整保留。末端约 1.30 s 是长输入、大模型、竞争和并发的组合结果，不能归因单一变量。用单变量对照理解各项作用。相邻差异表对并发相关性未建模，仅作描述；每档并发均值 CI 已按波次重采样。

## 证据与复现

单台 Windows 桌面、单 GPU、单引擎、现有 154 W 上限仍有显示及操作系统噪声，不能推广为显卡性能比例。候选均值选择有选择偏差；预试验最低与正式最低不同，独立阶梯也有波动。这里只有观察最小值，没有全局最优证明。

结果只衡量延迟，不证明质量等价、答案正确、FLOP 数、吞吐或生产表现。SQuAD 选中记录保留来源、答案、Wikipedia 标题链接和数据哈希，保持 CC BY-SA 4.0。权重、二进制、完整第三方数据集、私人日志和凭据未上传。
